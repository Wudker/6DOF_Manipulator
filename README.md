# Educational 6-DOF Robotic Manipulator – Engineering Thesis

This project presents an educational anthropomorphic robotic manipulator with six degrees of freedom, developed as an engineering thesis. It combines mechanical design, kinematic analysis, embedded control, custom electronics and software development. The system uses an ESP32 and a custom PCB to control six stepper-driven joints through a local web interface. Forward and inverse kinematics provide position control, while repeatability and positioning tests were used to validate the adopted assumptions and identify the prototype’s mechanical limitations.

## Technologies

`ESP32` `C/C++` `Forward kinematics` `Inverse kinematics` `WebServer` `Stepper motors` `DRV8825` `Custom PCB` `Belt transmissions` `3D printing` `CAD`

## Usage and development status

After assembling the hardware and uploading the firmware, the manipulator can be controlled through its local web interface. Before starting movement, verify the wiring, power supply and initial joint positions. The prototype was successfully built and tested; potential improvements include increased mechanical stiffness, more accurate calibration and smoother trajectory planning.
